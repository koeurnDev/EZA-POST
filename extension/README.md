# ⚡ EZA-POST Facebook Sync Helper (Official Chrome Extension)

Chrome Extension ផ្លូវការរបស់ **EZA-POST** សម្រាប់ជួយឱ្យ User និងអ្នកធ្វើ MMO អាចភ្ជាប់ Facebook Pages ចូលក្នុងប្រព័ន្ធ EZA-POST ដោយស្វ័យប្រវត្តិតាមរយៈ **១ ឃ្លីក (1-Click Sync)** ដោយមិនបាច់មាន Meta Developer App និងមិនបាច់ Copy/Paste អ្វីទាំងអស់!

---

## 🚀 របៀបតម្លើងលើ Google Chrome (Install in 30 seconds)

1. បើក Browser **Google Chrome**
2. ចូលទៅកាន់អាសយដ្ឋាន: `chrome://extensions`
3. នៅជ្រុងខាងស្តាំលើ បើកកុងតាក់ **"Developer mode" (របៀបអ្នកអភិវឌ្ឍន៍)** ឱ្យទៅជាពណ៌ខៀវ
4. ចុចប៊ូតុង **"Load unpacked"** (ផ្ទុកផ្នែកបន្ថែមមិនទាន់ខ្ចប់) នៅជ្រុងខាងឆ្វេងលើ
5. ជ្រើសរើស Folder: `D:\EZA POST\EZA-POST\extension`

---

## 🎯 របៀបប្រើប្រាស់ (1-Click Sync)

1. បើក Facebook របស់បងលើ Chrome ដូចធម្មតា
2. ចុចលើរូប Icon **EZA-POST Extension ⚡** នៅខាងស្តាំលើនៃ Browser Chrome
3. ចុចប៊ូតុង **`⚡ Sync Pages ទៅកាន់ EZA-POST (1-Click)`**
4. **រួចរាល់!** នោះ Facebook Pages ទាំងអស់នឹងរត់ចូលក្នុង EZA-POST Dashboard ភ្លាមៗក្នុងរយៈពេល **១ វិនាទី**!
